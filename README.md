# 丹东五十K · 六人实时在线牌桌

六人组队、三副牌的丹东五十K。Node.js 20+，WebSocket 实时同步，房间写入 JSON 文件，支持断线重连、40 秒出牌倒计时与机器人陪玩。

## 本地运行

```sh
npm install
npm start
```

浏览器打开 `http://localhost:8787`。可先点「5个机器人陪玩」单人开局，或创建真人牌桌后把链接（`http://localhost:8787/#room=XXXXXX`）发给朋友。

常用环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8787` | 服务端口；`0` 表示随机端口 |
| `DATA_DIR` | `./data` | 房间持久化目录（`rooms.json`） |
| `TURN_SECONDS` | `40` | 每回合倒计时；超时自动「不要」，领出超时自动出最小单张 |
| `BOT_DELAY_MS` | `900` | 机器人思考延迟 |
| `ROOM_TTL_HOURS` | `24` | 无活动房间清理时间 |
| `SAVE_DEBOUNCE_MS` | `400` | 落盘防抖 |
| `MAX_BODY_BYTES` | `32768` | 请求体上限 |

## 测试

```sh
npm test
```

使用 `node:test` 启动随机端口、临时数据目录的服务，覆盖：领出/跟牌两种超时、三小局完整对局与大局切换、SIGTERM 持久化重启、错误 token、WebSocket 实时推送。

## 玩法与功能

- 实时同步走 WebSocket（`/ws`）；WS 断开时自动降级为 850ms REST 轮询，恢复后自动切回。
- 身份 token 由服务端签发，所有操作按 token 推导座位；刷新页面自动回到原座位。
- 全员可见倒计时：顶栏、当前玩家座位徽标、自己回合的大号读秒；≤10 秒变红并提示音。
- 「提示」按钮枚举可压过上家的牌并循环选中；服务端做最终校验。
- 对手剩余张数、在线圆点、房主标记、中央出牌区与收分提示。
- 房间、比分、手牌与当前倒计时定期原子落盘，重启后恢复。
- 结算表含未出手分、扣分、合计与大皇队信息。
